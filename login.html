Google OAuth Client ID Belum Diisi

Agar pengguna dapat login menggunakan akun Google asli, masukkan Web Client ID dari Google Cloud Console ke file config.json:

  1. Buka Google Cloud Console → APIs & Services → Credentials.
  2. Buat OAuth 2.0 Client ID (Web application) dan tambahkan http://localhost:3000 (serta domain produksi Anda) di Authorized JavaScript origins.
  3. Salin Client ID ke field "googleClientId" di file config.json, lalu refresh halaman ini.

TerraGIS hanya membaca nama, alamat email terverifikasi, dan foto profil Google Anda untuk keperluan lisensi dan invoice.
